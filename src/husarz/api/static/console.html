Wtyczki (konektory MCP)

        
Wtyczka = zewnętrzny serwer narzędzi MCP. Konfiguracja w config/plugins/*.yaml (źródło prawdy). Token podaj jako referencję (np. env:HUSARZ_MCP_TOKEN). Endpoint lokalny (loopback) jest dozwolony; host publiczny wymaga https i wpisu w security.egress.allowlist. Odkrywanie (tools/list) oraz wywołanie (tools/call) — to drugie deny-by-default (allow_call + call_allowlist).
